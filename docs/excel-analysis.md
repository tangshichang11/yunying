## 重要公式提取

### 收入计算
```
收入合计 = 房费收入 + 迷你吧收入 + 餐费收入 + 其他业务收入
```

### 成本计算
```
变动费用合计 = 客房耗材 + 前台增值物品 + 小商品成本 + 餐厅 + 洗涤费 + 能耗
人工成本 = 前台工资 + 客房工资 + 餐厅工资 + 管理层工资
提成成本 = 前台好评提成 + 前台二维码提成 + 会员卡提成 + 客房提成
```

### GOP 计算 (UNKNOWN - 未明确找到)
```
GOP = 收入合计 - 变动费用 - 人工成本 - 提成成本
```
**ASSUMPTION**: GOP计算公式需向慧友确认

### 出租率
```
出租率 = 入住间数 / 实际间数
实际间数 = 133 (固定值)
```
