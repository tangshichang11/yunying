# Metric Definition Gap
# 经营指标口径差异

## 1. 当前系统数据

### 1.1 酒店基础数据
- 酒店: 龙口悦致酒店
- 总房间数 (actualRooms): 120

### 1.2 当日房态数据
| 字段 | 值 |
|------|-----|
| outOfOrderRooms (待修房) | 1 |
| outOfServiceRooms (自用房) | 1 |
| occupiedRooms (入住间数) | 61 |

### 1.3 可售房数计算

```
可售房数 = 总房间数 - 待修房 - 自用房
         = 120 - 1 - 1
         = 118
```

---

## 2. 当前系统公式

### 2.1 Occupancy (出租率)

```typescript
// 当前实现 (calculate.ts)
occupancyRate = occupiedRooms / actualRooms
              = 61 / 120
              = 50.83%
```

### 2.2 ADR (平均房价)

```typescript
// 当前实现
avgRoomRate = roomRevenue / occupiedRooms
            = 28000 / 61
            = 458.69
```

### 2.3 RevPAR (每可供房收入)

```typescript
// 当前实现
revpar = totalRevenue / actualRooms
       = 32800 / 120
       = 273.33
```

---

## 3. 行业标准公式

### 3.1 标准定义

| 指标 | 英文 | 行业标准公式 |
|------|------|-------------|
| 出租率 | Occupancy | 入住间数 / 可售房数 |
| 平均房价 | ADR (Average Daily Rate) | 房费收入 / 入住间数 |
| 每可供房收入 | RevPAR (Revenue Per Available Room) | 房费收入 / 可售房数 |

### 3.2 可售房数定义

```
可售房数 = 总房间数 - 当日不可售房间数
         = 总房间数 - (待修房 + 自用房 + 其他不可售)
```

---

## 4. 差异分析

### 4.1 Occupancy 差异

| 方案 | 公式 | 结果 |
|------|------|------|
| 当前系统 | 61 / 120 | 50.83% |
| 行业标准 | 61 / 118 | 51.69% |

**差异**: 0.86 个百分点

### 4.2 RevPAR 差异

| 方案 | 公式 | 结果 |
|------|------|------|
| 当前系统 (用总收入) | 32800 / 120 | 273.33 |
| 行业标准 (用房费收入) | 28000 / 118 | 237.29 |

**差异**: 36.04

### 5.1 关键问题

| # | 问题 | 选项 |

| 1 | Occupancy 计算基数是什么？ | A. 总房间数 / B. 可售房数 |

### 5.2 确认清单

- [ ] **Occupancy**: 应使用"总房间数"还是"可售房数(总房间数-待修房-自用房)"?

- [ ] **RevPAR**: 行业标准用"房费收入"，但当前系统用"总收入"。是否正确?

## 6. 公式验证

### 6.1 RevPAR = ADR × Occupancy

如果采用行业标准:

```
RevPAR = ADR × Occupancy
       = 458.69 × (61/118)
       = 458.69 × 0.5169
       = 237.29
```

### 6.2 验证结果

- **当前系统**: RevPAR = 273.33 (使用总收入/总房间数)
- **行业标准**: RevPAR = 237.29 (使用房费收入/可售房数)
- **公式一致性**: 不一致
