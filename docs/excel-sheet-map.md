# Excel Sheet 分类映射图

## 业务分类视角（非Excel Sheet直接映射）

根据业务实质，将39个Sheet重新归类为以下业务模块：

---

## 业务模块划分

### 模块 1: 客房收入管理
| Excel Sheet | 类型 | 业务含义 |
|-------------|------|----------|
| 收入及其他项目 | 录入+计算 | 客房基础收入数据（房费、迷你吧、餐费） |

**核心数据**:
- 入住间数 (每日)
- 平均房价 (ADR)
- RevPar
- 房费收入
- 迷你吧收入
- 餐费收入

## 数据归属关系

### 人员维度
```
员工 (来自各工资录入Sheet)
├── 前台部 (前台工资录入)
├── 客房部 (客房工资录入)
├── 餐厅部 (餐厅工资录入)
└── 管理层 (管理层工资录入)
```

### 成本维度
```
总成本
├── 变动成本
│   ├── 客房耗材
│   ├── 前台增值物品
│   ├── 小商品
│   ├── 餐厅原材料
│   ├── 洗涤费
│   └── 能耗
├── 人工成本
│   ├── 前台工资
│   ├── 客房工资
│   ├── 餐厅工资
│   └── 管理工资
├── 提成成本
│   ├── 前台好评提成
│   ├── 前台二维码提成
│   ├── 会员卡提成
│   └── 客房提成
└── 固定成本
    ├── 租金
    └── 平台推广费
```

## 数据库设计建议（业务实体视角）

### 实体: DailyRevenue（日收入）
```
日核算日期, 酒店ID, 入住间数, 平均房价, RevPar, 房费收入, 迷你吧收入, 餐费收入, 其他收入
```

### 实体: LaborCost（日人工成本）
```
日核算日期, 酒店ID, 部门, 员工ID, 基本工资, 岗位工资, 绩效, 日分摊工资
```

### 实体: VariableCost（日变动成本）
```
日核算日期, 酒店ID, 成本类型(枚举), 金额
```

### 实体: Commission（日提成）
```
日核算日期, 酒店ID, 员工ID, 提成类型, 数量, 单价, 金额
```

### 实体: DailyAccounting（日核算汇总）
```
日核算日期, 酒店ID, 收入合计, 变动成本合计, 人工成本合计, 提成成本合计, GOP
```
